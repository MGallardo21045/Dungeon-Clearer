# Dungeon Clearer

Dungeon Clearer is an in-development 2D top-down action game built using **C++ and SDL3**. The project focuses on implementing gameplay mechanics, enemy behavior, and modular game systems while strengthening my C++ and object-oriented programming skills.

## Features

- **Player Movement:** Frame-rate-independent movement with boundary and collision handling.
- **Combat System:** Attacks, projectiles, cooldowns, and combat combos.
- **Enemy AI:** Enemy behavior and interactions with the player.
- **Health and Damage:** Systems for tracking health, applying damage, and handling combat interactions.
- **Status Effects:** Timed gameplay effects.

## Technologies

- **C++** — Core game logic and object-oriented design
- **SDL3** — Window management, rendering, and input handling
- **CMake** — Project configuration and builds
- **Git & GitHub** — Version control

## Project Structure

The game uses a modular architecture to separate responsibilities across player, enemy, projectile, and core game systems.

## Development Status

**In active development.**

Dungeon Clearer is an ongoing personal project. Gameplay features, code organization, and overall polish are being developed and improved incrementally.
